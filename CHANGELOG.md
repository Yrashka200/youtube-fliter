# Changelog

## [1.3.0] - 2026-09-22

### Added
- Profiles — save multiple sets of settings and switch between them in one click, so you can focus on different topics (e.g. "Only Tech", "Only Music") without reconfiguring everything each time
- Filtering now also works on the video watch page sidebar, not just on the homepage

### Changed
- Improved settings export and import to include profiles

## [1.2.0] - 2026-09-19

### Added
- Hide videos by language (Russian / English) with automatic detection
- Custom block words input with tag list UI
- Import settings from JSON file with validation

### Changed
- Improved category keyword lists for Games, Music, Tech, and Crypto
- Video size options reworked: Small, Medium, Large, Cinema

### Fixed
- Hidden videos not restoring when filter was disabled
- Progress bar detection for watched videos

## [1.1.0] - 2026-09-15

### Added
- Automatic update checker from GitHub
- Changelog viewer inside the popup
- Update badge on the extension icon

### Changed
- Popup UI redesigned with cleaner sections
- Reset now clears all settings and profiles

## [1.0.0] - 2026-09-10

### Added
- Initial release
- Hide YouTube videos by category (Games, Sports, Politics, Music, News, Movies, Tech, Crypto, Kids)
- Hide Shorts
- Hide watched videos
- Custom video size adjustment
- Enable / disable filter toggle
- Welcome page on first install
- Uninstall feedback page
